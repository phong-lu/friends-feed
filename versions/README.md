# Saved versions

`version-1.zip` preserves the Chrome and Firefox extensions as approved before the startup timing improvement. Extract it to recover the Version 1 folders.

The working extensions remain in `src/chrome` and `src/firefox`.

`version-2.zip` preserves Version 2 (`2.0.0`) for both browsers, including earlier menu insertion at `document_start` and the modern blue gradient extension icon.

`version-3.zip` preserves Version 3 (`3.0.0`) for both browsers, with a solid Facebook blue (`#0866FF`) extension icon. Both browsers use identical content scripts, styles, icon assets, and content script configuration. Firefox additionally declares its add-on ID, minimum supported version, and no data collection.
