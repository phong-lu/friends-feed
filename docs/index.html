Facebook Friends Feed

Privacy policy

Effective date: November 17, 2026

This policy describes how Facebook Friends Feed, maintained by phong-lu, handles information. The extension adds a Friends feed shortcut beside Home in Facebook’s desktop navigation.

The extension works locally in your browser. It does not collect, store, or transmit personal data to the developer or any other recipient.

Information used in your browser

The extension reads the current Facebook page URL and examines navigation elements, links, and visual styles to place the shortcut and indicate when the Friends feed is active. It observes page layout changes so the shortcut remains available as you navigate. This processing occurs temporarily within the page in your browser.

The extension does not extract your posts, messages, friends list, account details, passwords, or cookies. It does not record your browsing history.

Site access and permissions

The extension’s content script runs only on facebook.com and www.facebook.com over HTTPS. This access is used to modify Facebook’s navigation. The current version requests no additional Chrome extension API permissions.

Storage, sharing, and tracking

The extension does not use cookies, local storage, or Chrome storage to save user data. It has no developer-operated server, analytics, advertising, telemetry, or remote code. It does not sell or share user data. Because the developer receives no user data through the extension, there is no extension user data held by the developer to retain or delete.

Facebook and other services

Clicking the shortcut opens Facebook’s Friends feed URL in your browser. Facebook processes that request and your use of its service under its own Privacy Policy. Facebook Friends Feed is an independent project and is not affiliated with or endorsed by Meta.

This privacy policy page is hosted on GitHub Pages. GitHub may process technical information when you visit this page under the GitHub Privacy Statement. This is separate from the extension’s local operation.

Your choices

You can disable or uninstall the extension at any time through your browser’s extension settings. Removing it stops its page access and navigation changes.

Changes to this policy

This page will be updated if the extension’s data practices change. The effective date above identifies the latest revision.

Contact

For privacy questions, open an issue in the project repository. Issues are public; please do not include personal or sensitive information.
